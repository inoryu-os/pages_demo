# Onboarding

This page is an example knowledge document for new team members.

## First Day Checklist

- Request access to GitHub, Slack, and project management tools.
- Read the architecture overview.
- Confirm the local development setup.
- Create a small documentation Pull Request to verify the workflow.

## Documentation Rules

- Keep pages short and focused.
- Prefer concrete commands and examples.
- Update related pages in the same Pull Request when behavior changes.
